# YouTube Playlist Viewer

## Overview

This project is a web application that offers a distraction-free environment for viewing YouTube playlists. Developed using the YouTube Data API, it allows users to paste YouTube playlist URLs or IDs to fetch and display only the relevant videos. The application is designed with a focus on simplicity and ease of navigation.

## Features

- **Distraction-Free Viewing**: Displays only the videos from a YouTube playlist, eliminating distractions like comments and recommended videos.
- **Paste Playlist URL or ID**: Users can easily fetch videos by pasting the YouTube playlist URL or ID.
- **Intuitive User Interface**: Designed with a focus on user experience, the interface is clean, simple, and easy to navigate.

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **Material-UI**: A popular React UI framework for building responsive and visually appealing interfaces.
- **Easy Peasy**: A simple state management library for React.
- **YouTube Data API**: Used to fetch and display playlist videos.
